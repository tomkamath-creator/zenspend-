# 🌿 SereneSpend by VK — Offline Expense Tracker & Budget Calculator

A peaceful, stress-free mobile app for tracking expenses, managing budgets, and scanning receipts. Built with **React Native & Expo**, SereneSpend by VK is **100% free, 100% offline, requires zero internet, no account sign-ups, and incurs zero cloud fees**.

---

## ✨ Features

- **Designed & Built by VK:** Elegant, modern financial crest branding with custom app icon and splash screen.
- **Peaceful Light Theme:** Soft off-white backgrounds (`#F7F9F6`), gentle sage green highlights (`#4E7257`), and clean white cards (`#FFFFFF`).
- **Offline Bill / Screenshot Scanner:** Take a photo or pick a screenshot; SereneSpend scans totals and dates completely offline and keeps the photo saved in your device storage.
- **Real-Time Budget Math:** Set a monthly budget, automatically subtract expenses, and view real-time totals for:
  - 📅 **Today (Daily)**
  - 🗓️ **This Month (Monthly)**
  - 📈 **This Year (Yearly)**
- **Safe Daily Allowance:** Intelligently calculates how much you can safely spend per day for the remaining days of the month.
- **Calendar Spending Heatmap:** Visual monthly calendar grid shaded by spending intensity in gentle sage green. Tap any day to inspect transactions.
- **Spreadsheet (CSV) Export:** One-tap export to open in Excel, Numbers, or Google Sheets.
- **100% Standalone APK:** Builds a true release Android binary with embedded Hermes bytecode — zero computer or Metro connection required.

## 📱 How to Build the APK on GitHub ($0)

1. Upload or push this folder to your GitHub repository.
2. Go to the **Actions** tab in GitHub.
3. The **"Build Android APK (SereneSpend)"** workflow runs automatically on push.
4. Once finished, download `SereneSpend.apk` from the **Artifacts** section and install it on your Android phone!
